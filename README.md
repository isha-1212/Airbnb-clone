# Airbnb Clone — Take-Home Assignment

A desktop-only Airbnb listing page clone built as part of the frontend take-home assignment.

## Features

- Pixel-accurate Airbnb-style listing page
- Hero image gallery
- Photo Tour
- Full-screen Lightbox
- Previous / next image navigation
- Keyboard navigation (`←` / `→`)
- Sticky section navigation
- Sticky booking card
- Date selection and dynamic night calculation
- Reviews, amenities, location and nearby places
- Smooth scrolling and UI interactions
- Accessibility-focused interactive elements

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React
- Wouter

## AI-Assisted Development

AI tools were used throughout the development process for:

- UI analysis
- Component planning
- Implementation
- Debugging
- Visual refinement
- Interaction and accessibility improvements

The implementation was developed independently and does not directly copy or lift source code from the reference application.

## Architecture

A production-scale vacation-rental marketplace architecture diagram is included with the submission.

It covers:

- Frontend / CDN
- API Gateway
- Backend services
- Database
- Search
- Caching
- Object storage
- Deployment and scaling
